# Gestão de Obras

Trabalho final de ADS, desenvolvido individualmente.

## Tecnologias

- JSF
- PostgreSQL
- Template Manhattan

## Requisitos do trabalho

- [ ] Login com filtro administrativo
- [ ] Pelo menos um Enum
- [ ] CRUD 1 (criar, editar, excluir, listar todos, listar buscando por um campo)
- [ ] CRUD 2 (criar, editar, excluir, listar todos, listar buscando por um campo)
- [ ] CRUD 3 (criar, editar, excluir, listar todos, listar buscando por um campo)
- [ ] Funcionalidade principal: gestão de obras (com relacionamento one-to-many com um dos CRUDs)
- [ ] Persistência com PostgreSQL
